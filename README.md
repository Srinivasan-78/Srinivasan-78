### 🏢 Enterprise track record

**Thomson Reuters — DevOps &amp; Platform Systems Engineer**
- Re-architected a multi-terabyte Azure Storage migration from a 48-hour weekend window to roughly 4 hours with **0% data loss**, using chunked delta detection and parallel AzCopy orchestration.
- Replaced multi-page manual recovery runbooks with single-click self-service GitHub Actions workflows — **RTO under 5 minutes**, including automated Azure NLB regional cutovers.
- Built a fail-fast synthetic validation gate that verifies service state, HTTP 200, load-balancer convergence, and the health-check file *before* live traffic is routed, with retry/backoff so a slow start is never mistaken for a failure.
- Drove double-digit-percentage cloud storage cost savings through tiering and lifecycle automation.

**Granite River Labs — Systems / DevOps Engineer**
- Automated the Project MATTER / CSA and Zigbee smart-home compliance test-runner image pipeline, with hardware-in-the-loop rigs and automated packet-capture diagnostics on GitLab CI.
- Cut compliance test-setup cycles by more than half.
- Architected multi-architecture (Buildx) container pipelines with semantic versioning, vulnerability scanning, and multi-registry push orchestration.
- Authored the Wireshark THREAD protocol Windows installer (WiX) — [merged upstream into Wireshark](https://gitlab.com/wireshark/wireshark/-/merge_requests/11008).
